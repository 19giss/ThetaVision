
# ThetaVision
### Handwritten Mathematical Expression Recognition Using Deep Learning

**AAI-521 | Applied Computer Vision for AI**  
University of San Diego

## Project Overview

θVision investigates how computer vision models recognize
handwritten mathematical expressions and convert them into
machine-readable LaTeX notation.

The project focuses on recognition accuracy, mathematical
notation complexity, and common model errors.

## Research Objectives

- Explore and preprocess handwritten mathematical images.
- Evaluate deep learning methods for mathematical recognition.
- Investigate model adaptation and fine-tuning.
- Analyze recognition performance and common errors.
- Examine how recognition reliability affects future
  educational AI applications.

## Dataset

Google Research — MathWriting (Human-Written Expressions)

https://huggingface.co/datasets/deepcopy/MathWriting-human

Current phase: Project setup and dataset exploration.

## Future Development

The long-term goal is to develop a student-facing AI tutor
capable of recognizing handwritten mathematical steps and
providing guided feedback.

An interactive image-upload demonstration may be developed
as an optional project extension.
